# Designing Typograph

Typograph makes typographic judgment explicit enough to discuss, test, and teach. The punctuation engine began this work by showing why a mark changed. The expanded system applies the same structure to the relationships around the words: an intention, an observable condition, a decision, a check, and an exception.

## Teach observation

The agent skill starts with the reader's task and the host product's identity. It asks agents to inspect the loaded fonts, actual content, and current styles before prescribing a scale. Shared principles distinguish established typographic concerns, house preferences, and browser constraints. Sentence case is the default for labels; small caps are assumed unavailable and must never be synthesized.

The specimen lets people change size, measure, leading, and paragraph space while reading the same passage. Hierarchy and numeral comparisons isolate another decision at a time. The CSS recipe follows the selected settings. The punctuation panel retains original/formatted comparison, protected code, inspectable reasons, and explicit replay controls.

These demonstrations are teaching instruments. The rhythm guide measures line intervals without claiming a baseline grid. The numbers example uses a font whose actual files support the forms being demonstrated. Unsupported hanging punctuation remains a clearly explained enhancement.

## The visual identity

The approved direction is elegant, minimalist, and informed by Bauhaus proportion and construction. A geometric T and point replace the former character mark. The monochrome palette uses #242424 ink, #8d8d8d gray, and #fcfcfc paper, with inferred neutral tones for surfaces, boundaries, and supporting text. Pure black and pure white are excluded. Asymmetric composition, square controls, and generous grouped space make the hierarchy legible. Saans carries the hero and interface; Serrif is the reading voice. Saans’s mono axis supplies code. The compact type scale tops out at 1.625rem (26px at the default root size), including specimen headings and numeral comparisons. Footer credits link both typefaces and Displaay Type Foundry.

Desktop puts a compact control rail beside a spacious specimen. Mobile stacks the same relationships. Labels use sentence case and natural spacing. Automatic dark mode and reduced-motion support carry through the whole interface.

## Independent tools

The punctuation engine remains a small deterministic English-language tool with exact-content protections, renderer adapters, and an explicit paragraph-buffered stream. Optional CSS supplies reading presets and small optical utilities. The skill operates independently and can improve a project without adding a package.

Shared principle records keep the website and skill aligned. Every build produces installable package and skill archives, so the preview's download actions work before registry publication. The package has a scoped prerelease name because the unscoped npm name is already taken.

## Evidence and next work

The repository checks punctuation behavior, streaming equivalence, renderers, new preset validation, redirects, and the actual package in a clean consumer. Browser verification covers the responsive specimen and its interactive comparisons. These are engineering checks, not a user study or a typography score.

Future work can extend the guidance through locale-aware punctuation, font diagnostics, justified text, and richer rhythm tooling. Each should earn its place through a concrete reading problem. The current system intentionally leaves editorial ambiguity visible and literal data intact.
