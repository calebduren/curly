# Curly visual direction

Accepted direction: a contemporary type specimen with restrained Western print influence. The interactive artifact leads the page.

- Warm chalk (#f7f5ef), near-black ink (#242522), proofreader vermilion (#bd3c2c), sage-green status ink (#416c51). Borders are quiet warm gray.
- Expressive serif identity and specimen; sober sans-serif controls and prose annotations; monospace for code and numerical evidence. Self-host font files and their licenses.
- First viewport: narrow Cowboy masthead, generous Curly wordmark beside the product promise, then a large split specimen with source and reading view. Controls are visibly attached to what they change.
- Signature interaction: switch original/formatted without changing typeface; optionally inspect each changed mark and the protected spans. Streaming is visibly labeled a replay.
- Actual entered text is the content. Examples expose tradeoffs, not artificial success metrics. Install instructions track the selected rules.
- Desktop uses a specimen sheet with a quiet control rail. Mobile stacks source and output with usable targets and no horizontal viewport overflow. Code scrolls locally.
- Animations are brief opacity/color transitions and streaming cursor feedback. Respect reduced motion. No decorative continuous motion.
- Focus indicators, properly labeled native controls, keyboard-operable inspection, legible contrast, local clipboard feedback, and composition-safe source editing.

Implementation proceeds from this agreed direction. Visual review will inspect desktop and mobile and record material findings before release.
